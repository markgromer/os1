# Inbox Notes

Status: manual structure ready. Automatic inbox capture and routing are planned work in [[context-memory]].

Inbox notes are temporary triage notes for facts that should not be lost but have not yet been assigned to a project, person, client, money, decision, or workflow note.

## Current Notes

- No inbox notes have been manually created yet.

## Capture Standard

Use inbox notes only as a short holding area. Each item should have an owner, target note, and next sorting action.

Move useful facts into the correct durable note. Delete or archive low-value notes after sorting.
