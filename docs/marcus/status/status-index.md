# Status Notes

Status: manual structure ready. Automatic current-status rollups are planned work in [[context-memory]].

Status notes are current snapshots: what is active, waiting, blocked, done, stale, risky, or needs Mark's attention now.

## Current Notes

- [[current-status]]

## Capture Standard

Each status note should include:

- scope of the snapshot
- current state
- active work
- waiting items
- blockers
- stale items
- next actions
- source and freshness

Status notes should be refreshed or superseded. Do not treat old status as current unless the note states when it was last verified.
