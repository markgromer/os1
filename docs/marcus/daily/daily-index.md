## Capture Standard

Each daily note should include:

- outcomes that changed project state
- decisions made or reversed
- blockers and follow-ups
- money, client, or relationship facts that need durable recall
- links to affected project, person, client, money, decision, or workflow notes

Do not store secrets, credential values, private message dumps, or low-value chat logs.
