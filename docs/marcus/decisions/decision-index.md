# Decision Notes

Status: manual structure ready. The root [[decision-log]] remains the durable Marcus system decision log.

Use this folder for standalone operational decisions that need their own note because they connect multiple projects, people, clients, money obligations, or workflows.

## Current Notes

- No standalone operational decision notes have been manually created yet.

## Capture Standard

Each decision note should include:

- decision date
- context
- decision
- consequence
- affected projects, people, clients, money notes, or workflows
- whether the decision is final, reversible, or pending review

System architecture decisions about Marcus itself should stay in [[decision-log]] unless they need a separate working note.
