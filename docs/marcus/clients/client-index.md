# Client Notes

Status: manual structure ready. Automatic client note creation and retrieval are planned work in [[context-memory]].

Client notes keep operational memory about organizations, buyers, vendors, and recurring relationships.

## Current Notes

- No client notes have been manually created yet.

## Capture Standard

Each client note should include:

- relationship owner and key contacts
- projects and services involved
- preferences, expectations, constraints, and approval habits
- open obligations, follow-ups, and risks
- linked money, people, project, and decision notes

Do not paste full contracts, credentials, or sensitive payment details into notes. Link to the responsible system or record by non-secret identifier when needed.
