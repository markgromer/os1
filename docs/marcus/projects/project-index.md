## Capture Standard

Each project note should include:

- objective and success criteria
- current status and latest meaningful update
- repo, site, provider, and local workspace references
- active requirements and known blockers
- client, person, money, workflow, and decision links
- next action

Keep implementation details in project notes only when they affect future operation. Put reusable methods in [[workflow-index]].
