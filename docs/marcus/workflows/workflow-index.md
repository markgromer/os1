## Capture Standard

Each workflow note should include:

- when to use the workflow
- required inputs
- exact steps, commands, routes, or checks
- approval boundaries
- verification evidence
- related projects or system notes

Keep workflows factual. Do not claim a provider, deployment, or integration works unless the note states when and how it was verified.
