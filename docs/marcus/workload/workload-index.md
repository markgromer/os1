## Capture Standard

Each workload note should include:

- active commitments
- priority and urgency
- blocked, waiting, delegated, or ready states
- next action
- risk to time, money, reputation, or delivery
- related daily, project, client, person, schedule, and money notes

Use workload notes for cross-project reality, not project detail already captured in project notes.
